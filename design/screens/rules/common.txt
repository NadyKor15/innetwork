ПРОЕКТНЫЕ ТРЕБОВАНИЯ (InNetwork, экран Echo Show 8 для Alexa+ add-on; приоритет выше шаблона, где они расходятся).
(А) Холст. Требование гайда Alexa+: макет авторится в базовом холсте 768×480 CSS px, а на <html> стоит zoom: 1.667, поэтому рендер при viewport 1280 даёт ровно 1280×800. Слова задачи «ширина ровно 1280 px в CSS» понимать так: body 768×480 CSS px + html{zoom:1.667} = рендер 1280×800, одна страница без прокрутки, overflow hidden. Все размеры (кегли, отступы, радиусы) — в базовых px. Картинка 1586×992: её координата ×0.4842 = базовые px.
(Б) Токены: блок :root и :root[data-theme="light"] из tokens.css — дословно в <style> (или <link rel=stylesheet href=tokens.css>); вне этих блоков никаких сырых hex/rgb, только var(); свои переменные — вторым блоком :root. Фон экрана var(--screen) (#14181E, тёмно-синий «как у Alexa»), а не тёплый фиолетовый с картинки — это решение Нади, оно главнее картинки. Карточки var(--card) с рамкой 1px var(--hairline) (карточка и фон одного цвета — карточку видно по рамке), вложенные поверхности var(--card-inner). Остальные цвета картинки переводить в ближайшие токены: коралл=var(--mom), лиловый=var(--older), бирюза=var(--youngest), мятный=var(--fits), розовый=var(--rose), жёлтый=var(--unknown), голубой=var(--file).
(В) Темы: тёмная по умолчанию; светлая через <html data-theme="light">. Разрешён ровно один inline-скрипт: <script>if(/[?&]theme=light/.test(location.search))document.documentElement.dataset.theme='light'</script>. В конце сделай ещё рендер светлой темы shots/screen-light.png (render.js с ?theme=light) и посмотри его глазами: всё читается, ничего не пропало.
(Г) Шрифт Nunito: @font-face из fonts/nunito-latin-{400,600,700,800}-normal.woff2 (относительный путь, font-display: block), font-family: var(--font). Шрифт картинки другой — остаток ±2–4 px по ширине строк допустим.
(Д) Шапка вместо логотипа внизу (гайд: логотип add-on — слева сверху): верхняя строка экрана высотой 24 базовых px, отступ слева 24: знак из logo-mark.svg (три круга, высота 12 базовых px; в светлой теме цвета из logo-mark-light.svg — сделай знак inline SVG с fill=var(--mom)/var(--older)/var(--youngest)) + слово «InNetwork» Body2 (14px) weight 700 var(--text-1); справа в этой же строке «demo data» Label1 (10px) var(--text-3). Логотип и «demo data» внизу экрана, как на картинке, — убрать. Всё остальное содержимое экрана сдвигается вниз на высоту шапки; освободившуюся нижнюю строку используй, чтобы сохранить пропорции блоков картинки. Пропорции, порядок и композиция блоков — как на картинке.
(Е) Галочка «подходит» — только контур галочки цвета var(--fits) БЕЗ кружка и заливки (на картинке заливные зелёные кружки — это вид другого проекта, запрещено). Статус «неизвестно» — жёлтый «?» в тонком контурном круге var(--unknown), без заливки. «Отсеян» — имя зачёркнуто var(--text-3), причина var(--rose) не меньше Body3.
(Ж) На коралловых и любых светлых плитках текст var(--on-accent) (тёмный), белый на коралле запрещён (контраст 2.3:1).
(З) Минимальный кегль: любой текст для клиента ≥ Body3 (12 базовых px); Label1 (10) — только бейджи, подписи осей и «demo data»; Label2 (8) не использовать. Мелкие подписи картинки (11–16px на 1280) поднять до этих минимумов. Радиусы: карточка 16, вложенная 12, бейдж 8, пилюля — круг. Отступы из шкалы 2/6/8/12/16/20/24 (поля экрана 24, внутри карточки 16, между карточками 12) — там, где это не ломает композицию картинки.
(И) Касание: любой нажимаемый элемент ≥ 48×48 px на устройстве (≈29 базовых px).
(К) Никаких логотипов Amazon/Alexa/Echo/страховщиков, звёзд, рейтингов, фото врачей. Имена врачей — только из брифа, дословно (вымышленные, прошли проверку по реестру NPPES). Слово «Alexa» — простым текстом.
(Л) Тексты — из брифа и с картинки; правки ниже, в разделе ЭКРАН, главнее и брифа, и картинки. Каждое отличие от картинки, сделанное по этим требованиям, — строкой в notes («по STYLE: …»).
(М) В конце notes допиши раздел «Данные экрана»: перечисли каждую переменную часть экрана (имена, даты, время, статусы, причины, числа) — эти строки потом будут подставляться из данных, вёрстка не должна ломаться при другой длине (длинное имя врача — многоточие не допускается, лучше перенос в 2 строки там, где это не число). Рядом — список CSS-классов главных блоков.
